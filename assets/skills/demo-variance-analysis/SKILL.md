# 月度资金计划差异分析(演示 Skill)

> 虚构示例,用于演示 Skill 渐进式披露;**非真实业务口径**。

编排多能力完成"计划 vs 执行"的差异分析。

## 步骤

1. **取数对比**:用 `query_finance_data` 取本期计划金额与执行金额,按科目汇总。
2. **确认口径**:用 `search_knowledge` 查"执行率 / 差异"的统计口径(是否含在途资金等)。
3. **定位差异**:对差异绝对值或比例最大的科目下钻明细。
4. **核对逻辑(可选)**:差异异常时派 `ask_codebase` 核对报表的计算实现。
5. **产出报告**:按"总览 → 重点科目 → 建议"模板输出,关键论断附取数与口径出处。

## 注意事项

- 金额口径以口径文档为准,不臆测;差异结论需给出处。
- 大表只回"摘要 + 句柄",按需分页下钻,不把明细整段塞进上下文。
